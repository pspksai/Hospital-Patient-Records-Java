# Hospital Patient Records Management System

## Project Description
This is a console-based Java application that manages hospital patient records. 
It allows registering patients, viewing all records, searching by patient ID, 
updating patient information, and deleting records.

## Technologies Used
- Java (Core Java)
- Eclipse IDE
- OOP Concepts
- ArrayList
- Scanner

## Features
- Register Patient
- Get Patient Details by ID
- Show All Patients
- Update Patient Information
- Delete Patient Record

## How to Run
1. Open project in Eclipse
2. Run HospitalApp.java
3. Follow menu instructions in console
